Payments

Check each receipt against the KPay statement: the amount, the time and the sending number. Approving gives the account Premium for the days chosen — nothing else does. A rejection's reason is what the payer's app shows.

Categories

The tab names in the app. Rename, hide, add — and move with ▲▼ — with no app build. Moving a category moves its whole section: the tab and, on All, its row, with every film in it (films belong to a category by its id, not its place). All always stays first. The id is not editable and never will be: every title stores it, so changing one would rewrite every title using it. Hiding a category hides its films from the front page as well as its tab.

Add a category

Start-up

Two different costs, and only one of them is about file size. Bitrate — megabits every second — decides whether a stream can keep up at all: a phone camera writes for archive quality, so a short clip can demand more per second than a whole feature and will stop and start for as long as anyone watches it. Speed test downloads 8 MB of a real file through the Worker, from this phone, so the two numbers can be compared instead of guessed at. The index is the second cost: an MP4 keeps one, and at the FRONT a player reads the head of the file and starts. At the END, it reads the head, finds no index, and seeks to the tail of a file that may be gigabytes away — one extra round trip before the first frame, which is a slower start rather than a stutter. Uploads made before the console learned to write the index first are in the second state, and re-uploading them from here is the fix.

Streaming copies

Every viewer gets the copy their connection can carry, chosen by their phone from what it has measured. Heavy uploads are queued for conversion automatically; anything older can be queued here. A job starts within five minutes and reports each size as it finishes, so the small one is watchable long before the big one is done — queued is waiting, running is being converted, ready has a full set.

Stream secret

The shared secret between the streaming Worker and request-playback. Generate it once, paste the same value into both — Cloudflare (Worker → Settings → Variables and Secrets → TOKEN_SECRET) and Supabase (Edge Functions → Secrets → STREAM_TOKEN_SECRET). It is never sent anywhere from this page.
32 random bytes. There is no required format — both sides hash whatever text they are given — so a password-manager output works just as well as this. Generating a new one invalidates every token already handed out, so anything mid-playback stops until the app asks again, which it does automatically.

From Telegram

Forward a film to the bot as a file, with the folder name as the caption. A runner starts the moment it arrives and puts it in the bucket within a few minutes; then choose which title it belongs to here, and the streaming copies are made automatically. Send it as a file and not as a video — Telegram re-encodes anything sent as a video, and the whole point is the original. Telegram stops at 2 GB; anything bigger still goes through Upload above.
A file a title uses cannot be deleted from here, and a deleted file is not gone at once: it waits in the bin for seven days and can be restored until then. A file touched in the last day is never offered for deleting — an upload looks unused until its title is saved.

Direct check

Asks R2 directly, without the inventory above. It only lists — to delete, use the folders above, where deleting goes through the bin. Unfinished uploads are what this adds: a large upload goes up in parts, and a phone that loses signal halfway leaves those parts in the bucket where no file listing shows them (R2 drops them by itself after seven days).
Viewers only ever stream from R2. A film forwarded to the bot also has a copy in Telegram, so R2 does not have to keep its original once its streaming copies exist — and a title nobody watches can leave R2 altogether and come back from Telegram when it is wanted. Nothing leaves R2 at once: it waits seven days in the bin, and is deleted only if the runner has seen the same file in Telegram in the last three days.
