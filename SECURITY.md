# Security

## Reporting a problem

Please report it privately, through this repository's **Security** tab →
**Report a vulnerability**. Do not open a public issue for it.

One person maintains this project, so please allow time for an answer. A
fix goes out as a new app version through the in-app updater, or straight
to the server.

## What is in scope

* the Android app (the latest release on this repository)
* the server functions in `docs/edge/` and the stream Worker in `docs/worker/`
* the console in `docs/studio/`

## Please do not

* test against accounts other than your own
* load-test or flood any server: every request is paid for
* keep or share any film, file or personal data you reach

## Supported versions

Only the latest release. The app updates itself, and every right it has is
decided by the server, so a fix on the server reaches every version at once.
